# Moq Hands-On

This folder now matches the three Moq scenarios described in the review notes:

- mail sender scenario with `IMailSender` and `CustomerComm`
- directory explorer scenario with `IDirectoryExplorer` and `DirectoryExplorer`
- player registration scenario with `IPlayerMapper` and `Player`

Open `MoqHandsOn.sln` and run `dotnet test` from this folder.
