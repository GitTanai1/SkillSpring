# NUnit and Moq Hands-On

This folder contains a self-contained NUnit/Moq practice solution that covers the lab topics exposed in the handout snippet:

- parameterized test cases with `TestCase`
- tests for methods that return values
- exception assertions with `Assert.Throws`
- tests for void methods and state changes
- Moq-based interaction testing with `Setup`, `Verify`, and `It.Is`

Open `NUnitMoqHandsOn.sln` and run `dotnet test` from this folder.
