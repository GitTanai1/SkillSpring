# EmployeeManagementSystem

Completed Spring Data JPA and Hibernate exercise project.

## Covered

- Spring Boot project with Spring Web, Spring Data JPA, H2, and Lombok dependency
- `Employee` and `Department` entities with one-to-many relationship
- Repositories with CRUD, derived query methods, `@Query`, and named query
- REST controllers for employee and department CRUD
- Pagination and sorting support for employee lists
- Entity auditing with created/modified metadata
- Interface-based and class-based projections
- Externalized data source configuration and explicit DataSource bean
- Hibernate-specific annotations and batch save operation

## Run

```powershell
mvn spring-boot:run
```
