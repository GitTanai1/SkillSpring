# orm-learn

Completed Spring Data JPA with Hibernate hands-on project.

## Covered

- Country entity, repository, service, CRUD, update, delete, and not-found exception
- Stock entity with Spring Data query methods
- Employee, Department, and Skill mappings
- Many-to-one, one-to-many, and many-to-many relationships
- HQL with `fetch`, aggregate query, and native query
- Quiz attempt HQL fetch query across user, attempt, question, options
- Criteria API product search example
- H2 seed data for all scenarios

## Run

```powershell
mvn spring-boot:run
```
