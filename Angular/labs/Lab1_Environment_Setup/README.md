# Lab 1: Environment Setup, Project Structure & First Component

## Topics Covered
- Angular CLI & Workspace Setup
- Angular Project Structure & Files
- Running & Building Angular Apps
- Creating Components

---

## Lab Exercise Goals
1. Scaffold a new Angular application using the standalone API.
2. Understand the core configuration files generated by the CLI.
3. Generate four key components for the Student Course Portal application.

---

## Step-by-Step Implementation

1. **Scaffold the Workspace:**
   ```bash
   npx -y @angular/cli@20 new student-course-portal --routing=true --style=css --package-manager=npm --interactive=false --skip-git=true
   ```

2. **Understand Workspace Files:**
   Refer to `notes.txt` inside the project root for detailed definitions of:
   - `angular.json`
   - `tsconfig.json`
   - `tsconfig.app.json`
   - `package.json`
   - `src/main.ts`
   - `src/app/app.config.ts`
   - `src/app/app.ts`
   - `src/index.html`

3. **Generate Core Components:**
   Generate components using Angular CLI:
   ```bash
   npx ng generate component components/header
   npx ng generate component pages/home
   npx ng generate component pages/course-list
   npx ng generate component pages/student-profile
   ```

4. **Customize Templates:**
   - **Header:** Define brand name and navigation links in `header.html`.
   - **Home:** Define statistics cards for Course Available, Enrolled, and GPA inside `home.html`.
   - **App:** Render `<app-header>` and `<router-outlet>` inside `app.html`.
